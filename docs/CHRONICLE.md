- 2026-08-01 [deadline]: 행사 페이지와 Terms의 일정 충돌과 무관하게 내부 마감은 2026년 8월 2일로 고정했습니다. Sergio가 해당 날짜를 기준으로 제작하기로 확정했습니다.

- 2026-08-01 [boundary]: 데이터 검증, 출처 추적, 범용 대시보드를 제품 주제로 삼지 않기로 했습니다.
