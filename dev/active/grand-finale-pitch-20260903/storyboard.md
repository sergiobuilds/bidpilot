# BidPilot Grand Finale Storyboard

This storyboard fixes the twelve-slide evidence sequence, central visual, on-screen labels, narration role, and timing.

**Contents**: 1 Narrative contract · 2 Slide plan · 3 Visual grammar · 4 Demonstration insertion · 5 Change history

## 1 Narrative contract

1. Founder authority establishes the origin of the product discipline.
2. Accounting-firm and enterprise friction define the operational problem.
3. Official global sources establish that the structure repeats across public-sector markets.
4. Verification, context, and strategy define the three requirements.
5. Snowflake and CoCo CLI each receive a separate necessity argument.
6. The real-tender `REVIEW` and historical replay `PURSUE` remain separate evidence paths.
7. Human approval remains the final legal-submission boundary.

## 3 Visual grammar

| Visual element | Fixed meaning |
|---|---|
| Public document outline | Tender source |
| Filled evidence node | Verified fact or supplier asset |
| Empty evidence node | Unresolved evidence requirement |
| Vertical aperture | Pursuit decision boundary |
| Proportional bar or arc | Official evaluation weight |
| WDS primary-blue path | Selected or verified execution path |
| Cool-neutral path | Alternative or contextual path |
| Caution marker | `REVIEW` or unresolved evidence |
| Inspection line | Red-team challenge |
| Named endpoint | Owned work |
| Continuous run spine | Same-run Snowflake persistence |

3.1 Slides 2 through 12 must allocate more visible area to the central visual than to text.

3.2 Equal KPI cards, three-column number tiles, generic dashboard grids, and rounded-rectangle process chains are prohibited.

3.3 Product screenshots are authenticity evidence on slides 7 and 8. They are not the primary composition.
